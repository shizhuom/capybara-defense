# 卡皮巴拉别慌！v1.0 · P1 贴纸精修版

独立的本地网页塔防小游戏。下半场由玩家操作，上半场是遵守同一套经济与合成规则的 AI；守住头顶橘子，获胜后带走双方本局全部碎片。

M3 在 M2 的 36 把神兵、12 英雄本命觉醒、黑市与九宫格扭蛋、8 主动 / 12 被动道具之上，补齐四张主题地图、12 位首领、54 段位、16 成就头像、本地温泉风云榜和程序化音乐音效。原 M1 调优节奏与 M2 全满测试档隔离机制保留。

P1 默认进入居中单屏玩家视图，390×844 手机也能完整操作。新加入全场合成配对光环、英雄金色底座、实时首领血条、五档段位 AI、首局三步引导与四分页百科；133 张正式贴图已同步覆盖地图、角色、道具、武器、头像和主视觉。

## 启动与停止

在本目录双击 **Start-Capybara.cmd**。脚本检查依赖、构建游戏、启动隐藏的本地服务，并尝试打开 **http://127.0.0.1:4175/**。当前机器已经装好依赖。若系统限制自动打开浏览器，直接打开上述地址即可。

双击 **Stop-Capybara.cmd** 停止由启动脚本创建的服务。重复启动会复用正在运行的本作服务；停止脚本通过专属记录及令牌识别服务，不会结束其他端口的程序。

环境：Windows、Node.js 22.12+ / 24 / 26+、现代 Chrome 或 Edge。全部运行文件、依赖和缓存都在本目录；游戏本身不需要外网。

开发命令（在本目录执行）：

```powershell
npm ci --offline --ignore-scripts  # 本机已有独立依赖缓存
npm run dev                      # Vite，固定 127.0.0.1:4175；Ctrl+C 停止
npm test                         # Vitest
npm run typecheck
npm run sync-assets              # 只读 design 原画，复制到本作 public/sprites
npm run build
```

换到没有缓存的电脑时，可用 `npm ci --ignore-scripts` 从 npm 获取锁定版本。启动脚本使用 Vite 构建产物；开发服务与启动脚本的服务不能同时占用 4175。

## 怎么玩

1. 点「开泡」，用「摇铃开饭」花固定 10 口粮抽取 5 只萌宠或组件，拖到下半场的白垫。窝里还有单位时可直接点「换一窝」：丢弃未摆放的剩余单位，支付 10 口粮重新抽 5 只；场上单位不受影响，口粮不足时保留原卡。也支持先点单位、再点目标格；折叠的精确点选区支持键盘操作。
2. 同种同级基础宠升星。动物与对应组件双向合成英雄；相同等级同名英雄可升星，英雄也可以吃自己的任一配方散件升级。英雄最高 5 级，蜜蜂最高 3 级。
3. 英雄合成或升级瞬间解除纸箱、淋湿、击倒和混乱；剪刀禁合必须等待结束。非合成配对交换位置，柴犬与魔法帽会触发拒戴彩蛋。
4. 拖小铁锹到草坪，花 1 把开荒；修复二哈毁格花 2 把。开局有 2 把，每 12 秒补充 1 把，每 3 波另加 1 把，最多存 6 把。暂停会停止生产，满仓不会积压产量。
5. 暂停可以查看双方战利品，继续战斗或投降。普通害虫越线扣 1 橘子，首领扣 2；一方橘子归零立即结束。
6. 棋盘下方左侧「草坪洒水车」每局免费用一次：120 冲洗伤害、击退 4.5 格、减速 2 秒，并解除己方纸箱封印。AI 也会在敌人接近终点时使用自己的洒水车。

开局有 20 秒摆阵；正常 1 倍速下，第一只首领在第 4 波、约 108 秒出现（开发者跳波/刷首领会提前）。首波老鼠由 58 血降至 24 血，1 级仓鼠两次普通攻击可击杀。拆家二哈每 24 秒毁一格，同半场最多同时存在 2 块坏地；修好后仍可能再次被破坏。双方使用相同的经济和产出规则。

左侧测试台提供 +500 口粮、指定 19 种抽卡单位、双方刷出任意 12 首领、增减橘子、跳波、倍速与重置本作存档。还可指定 0~53 段位及四张测试地图，下局生效。测试地图是本页临时选择，不授予普通档地图解锁；主菜单选图、恢复普通档和重置会清除该临时选择。中/EN 可随时切换，包括衣帽间、黑市、名片、榜单、设置、暂停、配方和结算弹窗。

12 位英雄均有实际普攻和自动大招：功夫阿宝、食铁兽教父、太极滚滚、靴子剑客喵、加特林喵、喵利波特、斩铁修勾、疾速旺财、无名刀鹅、铁山靠鸡神、拾荒浣熊王、孤寡蛙王。游戏内配方小抄展示全部配方及技能。

## 神兵与黑市

- **神兵衣帽间**：冷兵器、热兵器、法器各 12 把。Boss 和黄金铁锹宝箱产出真实神兵碎片，获胜带走双方掉落；集满自动解锁。英雄只能穿同系神兵，一把神兵同时只配一位英雄，转移时自动卸下。橙武给对应英雄额外觉醒。勾选品质可回收超过解锁门槛的碎片换金币。
- **浣熊黑市**：每天提供 3 件未满级道具，20 金币刷新，购买到满级后补货。金牌训宠证可买到 3 级。九宫格优先用免费券，否则花 80 金币；每赢一局加 1 张券，抽中已满级道具会折为金币。
- **局内道具**：开局前最多配 2 个主动和 6 个被动，当前局的配装固定。主动道具可点击后选目标或拖到目标；猫薄荷、罐头直接点击生效。被动自动生效，图标悬停查看说明。奶瓶升级也可立即解封，临期罐头有扣命风险。
- **快速体验**：后院测试台点「一键全满 M3 测试档」，获得 9999 金币、全部神兵和道具、最高段位、四地图、16 头像及12英雄图鉴；12 英雄自动穿本命橙武。用下拉框配置 2+6 后开局。点「恢复普通存档」恢复开启测试前的进度，测试所得不会带回普通档。重复开启不会覆盖普通档备份。

局中成功切换普通档/测试档时，会丢弃尚未结算的旧局并回到主菜单；恢复写盘失败则保留当前对局和备份。已在测试档中重复开启全满，或普通档没有备份时点击恢复，均不会中断当前同身份对局。

刀鹅大招可见连续残影冲刺，篮球与毛线球沿怪群逐段弹跳；纸箱封印、淋湿乌云、洗衣机、粘鼠板和肥橘救援都有独立演出。

## 四季地图、晋升与声音

- **四张地图**：阳光后院、樱花温泉馆、深夜厨房、猫爬架迷宫，均为 8×10 中心对称棋盘，每侧 16 个正交航点。历史最高段位达到 0 / 10 / 20 / 30 时永久解锁；主菜单可以跟随当前段位，也可以手选已解锁地图。厨房含 U 型半岛，迷宫含竖井与顶部走廊。
- **12 位首领**：在原六位之上，新增策反基础宠的波斯猫、击倒宠物的拳王袋鼠、召蜂的马蜂后、混乱停火的土拨鼠、招魂骨鼠的垃圾浣熊和群体回血加速的鼠王。首领在第 4 / 6 / 8 / 9 / 10 波按主题轮换，高段位混编；新控制同样可通过合成升级立即解除，六位均接入 EMP 反噬。
- **54 段晋升**：胜利 +1 星，三连胜起每胜 +2 星；前 10 段失败不掉星，之后失败 -1 星且不低于 20 星。前 50 段每两星晋级，最后四阶为 100 / 125 / 150 / 180 星。高段怪物血量、胜利基础金币和紫橙掉率随段位提高；本局数值在开局时固定。
- **头像名片和风云榜**：点击顶栏卡皮巴拉标志或段位卡，选择头像并查看 16 项条件；满足胜场、连胜、英雄合成、收藏或段位要求后自动解锁。风云榜展示本人及 15 位本地趣味 NPC，不是联网排名。
- **设置和声音**：顶栏齿轮可分别调节 BGM / 音效音量、关闭伤害飘字并切换语言，修改即时保存。默认使用 WebAudio 多声部 Menu Chill / Garden March / Boss Rush，首次点击或按键后开始；弹窗切舒缓音乐，后台降低音量，命中音效全局至少间隔 95ms。可用 `public/audio/manifest.json` 覆盖音乐和音效，开发服务与构建会过滤缺失文件；浏览器音频不可用时静默运行。
- **衣帽间精修**：36 把神兵各有贴纸图标，顶部展示12位英雄当前配装，支持默认和橙品优先排序。

两份权威规范中的最终 8×10 矩阵及明确路径数组已采用；路径是 16 节点、15 段。英雄每级所需能量乘 0.9，普攻按整数次触发。未给定的十波存活平局按橘子、击杀、累计伤害依次比较；完全相等时玩家胜。当前每波间隔 36 秒，第 10 波在 324 秒开始；清理最后一波后结算，橘子提前耗尽则提前结束。用户最新的试玩调整要求覆盖原 M1 的单抽及前期数值。
