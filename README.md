# 卡皮巴拉别慌！v1.0 · P2 单人温泉保卫战

独立本地塔防小游戏。整块 6×7 棋盘归玩家使用，沿四张蜿蜒地图布阵，守住卡皮巴拉头顶的橘子。撑过十波并清光害虫即获胜，带回本局收集的神兵碎片。

保留 12 位英雄、36 把神兵、12 位首领、20 种道具、54 段位、16 成就头像、黑市与九宫格扭蛋、温泉风云榜、三态音乐、首局引导与双语百科。P2 改为递增抽卡费、宠物窝出铲子，并新增可见持武与旋斩、突刺、远程后坐力演出。

## 启动与停止

双击 **Start-Capybara.cmd** 构建并启动，打开 **http://127.0.0.1:4175/**。双击 **Stop-Capybara.cmd** 停止本作服务。若当前已有服务，启动脚本会复用它；修改源码后请先停止再启动，以加载新构建。

默认是居中单屏玩家模式，390×844 手机与桌面均可完整操作。通过 `?dev=1` 或设置中的「开发者沙盒面板」开启测试台。测试台可以发粮、发宠物/组件/铲子、召唤单个首领、换地图/段位、调生命、跳波和倍速。

环境：Windows，Node.js 22.12+ / 24 / 26+，现代 Chrome 或 Edge。依赖、配置和缓存均在本目录，游戏运行不依赖外网。

```powershell
npm ci --offline --ignore-scripts
npm run dev           # Vite，127.0.0.1:4175；Ctrl+C 停止
npm test
npm run typecheck
npm run build
npm run sync-assets   # 只读 design 原画，复制到本作 public/sprites
npm run test:browser  # 在 Vite 运行时验证 P2 交互及截图
```

没有 npm 缓存的电脑可执行 `npm ci --ignore-scripts`。开发服务与正式启动脚本不能同时占用 4175。

## 怎么玩

1. 开局 **22** 口粮、**1** 把袋装铲子，首波出怪前有 **18 秒** 准备。每次摇铃抽满五格，费用为 **10 → 12 → 14 → 16…**；窝里有剩余单位时可以付本次费用换一窝，场上单位保留，钱不足不丢旧牌。
2. 拖拽或点选萌宠到白色空垫。同种同级基础宠升星；配方散件双向合成英雄，同名同级英雄或配方散件喂养可继续升级。英雄最高 Lv.5，蜜蜂最高 Lv.3。合成升级解除纸箱、淋湿、击倒、混乱；剪刀禁合需等待。
3. 五格窝会抽出铲子，单次最多两把。窝内铲子可直接拖到草坪开荒、拖到坏地分步修补，或拖到右侧铲袋储存；也支持点选后点击目标。坏地需两铲，可各修一次；袋里有两铲时一次点按就能修好。
4. 铲袋每 **55 秒**补一把、上限 **4**；自动发铲机改为每 **30 秒**、上限 **6**。满袋停止累计，暂停不计时。窝内铲子不参与合成/训练，可以回收换 **4** 口粮。
5. 普通害虫击杀固定 **+1** 口粮；首领 **+8** 并掉 1–2 片神兵碎片。第 2–10 波开场补 **3** 口粮。蜜蜂 Lv.1/2/3 分别每 18/11/7 秒产 1/1/2 口粮。
6. 普通害虫抵达温泉扣 1 橘子，首领扣 2；橘子耗尽或投降失败。十波后清光害虫且尚有橘子即胜利，金币为段位基础奖励加 `min(45, floor(剩余口粮×0.5))`，并带回收集碎片、加星和一张免费扭蛋券。
7. 「草坪洒水车」每局免费一次：120 冲洗伤害、击退 4.5 格、减速 2 秒，并解除己方纸箱封印。温泉加餐券给 +4 橘子，但害虫血量 +15%；狂欢派对给萌宠攻速 +38%，但害虫移速 +12%。

四张地图为阳光后院（18 路点）、樱花温泉馆（21）、深夜厨房（23）、猫爬架迷宫（22）。每张都有六块初始空垫；守护者及终点救援按当前地图终点定位。Boss 在第 4 / 6 / 8 / 9 / 10 波按主题轮换，高段位混编；每波间隔 36 秒。

## 神兵、道具与存档

衣帽间按冷兵器、热兵器、法器分系，集齐碎片自动解锁、同系穿戴、橙武本命觉醒，溢出碎片可回收。战斗中的英雄握持当前神兵；没有装备时显示默认武器，品质越高手持尺寸越大。近战显示旋斩、重劈或突刺，远程显示瞄准后坐与主题弹体，法器悬浮施法。

黑市每天提供三件道具，可付费刷新；九宫格优先使用免费券。开局前装备最多 2 主动 + 6 被动；主动支持点击/拖拽释放。全部英雄、首领、神兵与道具参数可在四分页《温泉图鉴百科》查看。

全满测试档与普通存档隔离：开启前自动备份普通进度，重复开启不覆盖备份；「恢复普通存档」还原原进度。局中成功切换身份会回到菜单并丢弃未结算旧局，写盘失败保留旧局和备份。

存档仍使用 `capybara_defense_v1:profile`，语言与普通档备份同前缀。旧档金币、胜场、收藏、段位、设置和奖励收据均保留；局内抽卡计数每局重新从 0 开始。新手教程完成奖励 20 金币且只领一次，可跳过并在设置中重看。

## 美术、声音与目录

`public/sprites/` 包含 **145** 张 PNG 与完整 ID 清单：四张 768×896 单人地图、所有角色和物件、20 道具、36 神兵、16 头像、主视觉，以及四把基础武器和八张战斗特效。运行同步脚本只读取 `../../design/assets/sprites/`，不会改动原画。无外图时保留 Canvas/SVG 回退。

`public/audio/manifest.json` 可覆盖三态音乐和音效；默认使用 WebAudio 程序化多声部。首次交互后启用音频，无 AudioContext 时静默降级。音量、飘字和语言均可在设置调整。

```text
src/config/       地图、数值、英雄/神兵/道具、持武与攻击风格表
src/core/         无 DOM 单人仿真、合成、Boss、经济及局外养成
src/render/       棋盘贴纸、动态持武、战斗 VFX、图片覆盖
src/ui/           菜单、HUD、黑市/衣帽间、百科、引导、声音与存档
src/i18n/         中英实时切换
public/           本地美术与可选音频
scripts/          启停、同步、隔离核验及浏览器回归
verification/     测试结果、实机截图与隔离证据
```

`npm run test:browser` 使用本机 Chrome 和独立测试浏览器环境；可通过 `CAPY_CHROME` 指定浏览器。正式构建可运行 `node scripts/production-smoke.mjs`、`node scripts/p2-production-qa.mjs`、`node scripts/m3-profile-switch-qa.mjs --label=p2` 验证。M1–P1 的历史验收和对应旧坐标脚本仍留档，不作为 P2 数值标准。

P1 回退点在本目录独立 Git 仓库：提交 `319ea6c`，标签 **`v1.0-p1`**。可以从该标签创建新分支继续另一版本，避免覆盖当前进度。浏览器存档独立于 Git；回退代码前请另存存档。

P2 完整基线保存在 **`p2-solo-overhaul`** 分支、标签 **`v1.0-p2`**。最新验收为 **686 项测试通过**，详情及实机截图见 [P2 交付验证](docs/P2-verification.md)。

所有修改限定本游戏目录。原三国基线、根脚本和 `design/` 只读；端口保持 4175。生产构建使用相对资源路径，可部署在 HTTP 子目录。
