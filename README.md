# 卡皮巴拉别慌！v1.0 · P6 温泉庆功卷轴与策略助手

独立本地塔防小游戏。1280×720 横屏舞台内的整块 9×5 棋盘归玩家使用，沿四张蜿蜒地图布阵，守住卡皮巴拉头顶的橘子。撑过十波并清光害虫即获胜，带回本局收集的神兵碎片。

保留 12 位英雄、36 把神兵、12 位首领、20 种道具、54 段位、16 成就头像、黑市与九宫格扭蛋、温泉风云榜、三态音乐、首局引导，以及 P2 的递增抽卡费、窝内铲子和动态持武。P3 加入全景庭院菜单、两帧行走、图标 HUD、局内实时属性卡与六分页可视化合成图鉴。

保留 P4 的萌宠温泉聚会插画、动态蒸汽、四种地图气氛、中英文无框艺术字、异形木牌开始按钮和四角圆形入口。P5 加入六类手账子页面、五步保底合成教学、安全点选与多维段位难度。P6 补齐暂停与胜负结算卷轴、合成继承的 MVP 战绩、下波预告与提前迎战、可合闪星和单格锁宠，并修好手机教程与属性卡的避让。全部 **193** 张 PNG 随游戏本地提供，未解码时显示 Canvas / SVG 兜底；旧存档继续兼容。

## 启动与停止

双击 **Start-Capybara.cmd** 构建并启动，打开 **http://127.0.0.1:4175/**。双击 **Stop-Capybara.cmd** 停止本作服务。若当前已有服务，启动脚本会复用它；修改源码后请先停止再启动，以加载新构建。

默认是居中 16:9 单屏玩家模式，适配桌面与 844×390 手机横屏；竖屏仍可操作，并显示可关闭的横屏提示。通过 `?dev=1` 或设置中的「开发者沙盒面板」开启浮动测试抽屉。测试台可以发粮、发宠物/组件/铲子、召唤单个首领、换地图/段位、调生命、跳波和倍速，并保留键盘棋盘操作。

环境：Windows，Node.js 22.12+ / 24 / 26+，现代 Chrome 或 Edge。依赖、配置和缓存均在本目录，游戏运行不依赖外网。

```powershell
npm ci --offline --ignore-scripts
npm run dev           # Vite，127.0.0.1:4175；Ctrl+C 停止
npm test
npm run typecheck
npm run build
npm run sync-assets   # 只读 design 原画，复制到本作 public/assets/sprites
npm run test:browser  # Vite 下验证 P6 全流程及 P5/P4/P3 浏览器回归
```

没有 npm 缓存的电脑可执行 `npm ci --ignore-scripts`。开发服务与正式启动脚本不能同时占用 4175。

## 怎么玩

1. 开局 **22** 口粮、**1** 把袋装铲子，首波出怪前有 **18 秒** 准备。每次摇铃抽满五格，费用为 **10 → 12 → 14 → 16…**；窝里有剩余单位时可以付本次费用换一窝，场上单位保留，钱不足不丢旧牌。
2. 拖拽或点选萌宠到白色空垫。同种同级基础宠升星；配方散件双向合成英雄，同名同级英雄或配方散件喂养可继续升级。英雄最高 Lv.5，蜜蜂最高 Lv.3。合成升级解除纸箱、淋湿、击倒、混乱；剪刀禁合需等待。
3. 五格窝会抽出铲子，单次最多两把。窝内铲子可直接拖到草坪开荒、拖到坏地分步修补，或拖到左侧铲袋储存；也支持点选后点击目标及属性卡快捷入袋。坏地需两铲，可各修一次；袋里有两铲时一次点按就能修好。
4. 铲袋每 **55 秒**补一把、上限 **4**；自动发铲机改为每 **30 秒**、上限 **6**。满袋停止累计，暂停不计时。窝内铲子不参与合成/训练，可以回收换 **4** 口粮。
5. 普通害虫击杀固定 **+1** 口粮；首领 **+8** 并掉 1–2 片神兵碎片。第 2–10 波开场补 **3** 口粮。蜜蜂 Lv.1/2/3 分别每 18/11/7 秒产 1/1/2 口粮。
6. 普通害虫抵达温泉扣 1 橘子，首领扣 2；橘子耗尽或投降失败。十波后清光害虫且尚有橘子即胜利，金币为段位基础奖励加 `min(45, floor(剩余口粮×0.5))`，并带回收集碎片、加星和一张免费扭蛋券。
7. 「草坪洒水车」每局免费一次：120 冲洗伤害、击退 4.5 格、减速 2 秒，并解除己方纸箱封印。温泉加餐券给 +4 橘子，但害虫血量 +15%；狂欢派对给萌宠攻速 +38%，但害虫移速 +12%。
8. 波次栏旁可预览来袭害虫及首领；点击预告查看克制贴士。非教学准备期或提前清场后的等待期，可吹号角立即迎战，额外奖励 **3–10** 小鱼干。首波奖励上限 **8**，敌人未清光或仍有副首领待登场时不可提前。
9. 点击窝左上角铜锁或属性卡的小锁，免费锁住 **1 格**，摇铃只替换其余 **4 格**，费用照常递增。上场、合成、换位、回收或铲子入袋后自动解锁。金色闪星提示可合英雄，小闪星提示升星/喂养；摇铃上方的提醒不拦截点击。

四张地图为阳光后院（21 路点）、樱花温泉馆（25）、深夜厨房（25）、猫爬架迷宫（21）。每张都有六块初始空垫；守护者及终点救援按当前地图终点定位。常规 Boss 在第 4 / 6 / 8 / 9 / 10 波登场。Rank 15 起加入双 Boss，Rank 20 起第 3 波出现先锋 Boss，Rank 45 起第 6 / 8 / 9 / 10 波均有双 Boss；副 Boss 延后 5 秒且与主 Boss 不同。波次至少间隔 36 秒，并等待本波额外敌人全部生成，第 10 波必须清空全部怪物才结算。

段位难度同时增加血量、移速、怪物数量、精英护甲与首领技能频率。Rank 0→53 血量为 1→6.2 倍，速度为 1→1.28 倍，每波额外 0→13 只；胜利段位基础金币为 60→220。新手 Rank 0 教学局血量为 0.85 倍。名片与段位页面均展示当前强度。

选中棋盘或窝内单位可查看实际伤害、攻速、射程与合成搭档，书本按钮直达相应图鉴。基础战斗宠物的 Lv.1–5 伤害倍率为 1 / 1.55 / 2.25 / 3.15 / 4.3；组件只能 Lv.1，蜜蜂最高 Lv.3，英雄仍使用 1.6 的逐级倍率。

轻点空白、草地、道路或已选单位可取消选中。窝内萌宠点空垫可以部署；棋盘萌宠点空垫仅取消选中，移位与换位用拖拽。点另一只可合成单位会合成，否则切换到对方属性卡，避免误换防线。

## 神兵、道具与存档

衣帽间按冷兵器、热兵器、法器分系，集齐碎片自动解锁、同系穿戴、橙武本命觉醒，溢出碎片可回收。战斗中的英雄握持当前神兵；没有装备时显示默认武器，品质越高手持尺寸越大。近战显示旋斩、重劈或突刺，远程显示瞄准后坐与主题弹体，法器悬浮施法。

黑市每天提供三件道具，可付 20 金币刷新；九宫格优先使用免费券，无券时每次 60 金币。装备最多 2 主动 + 6 被动；主动支持点击/拖拽释放。战斗顶部的商店按钮暂停游戏，提供神兵锻造坊与黑市切换：首个敌人出现前的换装立即生效，之后的购买和换装用于下一局。关闭时恢复进入商店前的暂停状态。神兵卡上的四位同系英雄头像支持一键穿戴，再点当前穿戴者即可卸下。

《温泉图鉴百科》包含合成矩阵、萌宠数值、传说英雄、捣蛋怪物、奇葩神兵、黑市道具六页。英雄预览标出一把真实本命神兵及两把同系推荐，详细成长表与实战共用数值函数。

全满测试档与普通存档隔离：开启前自动备份普通进度，重复开启不覆盖备份；「恢复普通存档」还原原进度。局中成功切换身份会回到菜单并丢弃未结算旧局，写盘失败保留旧局和备份。

存档仍使用 `capybara_defense_v1:profile`，语言与普通档备份同前缀。旧档金币、胜场、收藏、段位、设置和奖励收据均保留；局内抽卡计数每局重新从 0 开始。五步新手教程为：摇铃 → 部署 → 仓鼠升星 → 熊猫与斗笠合成英雄 → 打开图鉴。教学首包固定含两只仓鼠、熊猫、斗笠与松鼠；教学期间驻停准备计时，完成或跳过后至少保留 8 秒准备。完成首次奖励 20 金币，在设置重温会立即开启新的教学战局，奖励不会重复领取。

## 美术、声音与目录

`public/assets/sprites/` 包含 **193** 张 PNG 与完整 ID 清单：保留全部场景、角色、行走帧、武器、特效、启动页及 P5 手账资源；新增胜利、惜败、暂停、MVP、开锁/闭锁、号角和合成闪星八枚贴纸。运行同步脚本只读取 `../../design/assets/sprites/`，不会改动原画；来源清单完整时按原字节复制。无外图时保留 Canvas/SVG 回退。

`public/audio/manifest.json` 可覆盖三态音乐和音效；默认使用 WebAudio 程序化多声部。首次交互后启用音频，无 AudioContext 时静默降级。音量、飘字和语言均可在设置调整。

```text
src/config/       地图、数值、英雄/神兵/道具、持武与攻击风格表
src/core/         无 DOM 单人仿真、合成、Boss、经济及局外养成
src/render/       全景地图、两帧步态、动态持武、战斗 VFX、图片覆盖
src/ui/           庭院菜单、HUD、局内属性卡、黑市/衣帽间、六页百科与存档
src/i18n/         中英实时切换
public/           本地美术与可选音频
scripts/          启停、同步、隔离核验及浏览器回归
verification/     测试结果、实机截图与隔离证据
```
