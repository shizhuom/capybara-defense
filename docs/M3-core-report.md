## 实现

- `config/maps.ts` 精确四图矩阵、16正交航点与180度旋转下半场，主题数据和默认兼容MAP/PATHS导出。所有引擎独立克隆grid，路径数据不写入。
- `GridSystem/BattleEngine/OpponentAI/PropSystem` 依state.mapId行进、击退、洒水车、巨橘和AI选址，默认后院保持M1；STAGE和命中坐标未变。
- `config/enemies.ts` 加六Boss和killer_bee/charmed_rat，原9种配置未改。`BossMechanics.ts` 独立处理六新机制，共用BattleEngine的EMP门。
- 波斯猫按最低等级/id选合格基础宠（含1级蜂），移除后同位置召唤45血/.58速迷弟；袋鼠半径2最多2个击倒9秒；土拨鼠半径2.2最多2个混乱6.5秒；均可升级/合成即时解控。
- 蜂后前方.3/.6/.9召唤36血/.62速蜂；垃圾浣熊附近-.3/0/.3召唤rat×当前波次×1.3，骨盾标记表明增强生命，不叠未规定血量。召唤进度夹0..15，下一仿真步照常扣命，召唤物不充当Boss掉碎片。
- DJ本半场所有活怪（含自己）回12%maxHP，上限maxHP；4秒×1.3移动加速，重复刷新不乘方堆叠。移动按当前步实际剩余buff时间计算，过期不拖尾。
- `bossForWave`在4/6/8/9/10波按四主题阵容登场，四图覆盖12Boss；rank>=40种子随机混编，双方同一Boss。原普通怪数量/间隔/血量表、20秒准备与36秒波长保留。
- 开局快照rankIndex决定所有敌血倍率、胜利基础金币+原口粮奖励、紫橙掉落权重倍率；Boss和金铲统一rollWeaponFragment。末版rank0基础35币、高段160币。
- 合成成功产出英雄时去重记录state.mergedHeroes[side]；即便单位后来被移除也带入result。新英雄合体purge带legendary标记供独立合体和弦，升级仍普通琶音。
