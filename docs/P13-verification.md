# P13 / v2.4 验证记录

日期：2026-11-15（America/Los_Angeles）。实施依据为只读的 `design/codex_v2_p13_ux_endless_visual_report_spec.md`。

## 已实现的七项升级

1. **提前迎战指引**：按钮显示「提前战 +N」，首次可提前迎战时出现聚光灯、向导水豚与操作气泡。`earlyWaveTipSeen` 兼容旧存档，点击确认或成功迎战后保存；重温教程会重置提示。五步教学保持原契约，完成奖励仍只发一次。气泡避让属性卡、HUD、被动栏及教程完成 Toast。
2. **主动技能拖拽**：洒水车和八种主动道具统一支持点击、鼠标拖拽与触摸拖拽。指针由持久根容器捕获，按钮重绘不打断释放；关闭原生图片拖拽。单位目标支持棋盘/备战席合法目标与 68 舞台像素吸附，道路陷阱高亮可用道路，全场技能高亮棋盘边缘。跟随光标绘制 74px 道具贴纸，拖到无效位置取消且不消耗冷却/次数。
3. **盾牌排版**：使用 SVG 弧形丝带文字；段位称号、进度条、金币奖励分行。「守卫成功 / 澡盆失守 / 无尽凯旋」均有英文版本。中英短屏与竖屏结算经过截图检查。
4. **图像战报**：数据抽屉改为无内框的 MVP 聚光舞台、伤害/击退图章、战利品贴纸陈列与地图/波次/时间/橘子足迹条。新解锁内容随宝箱展示；保留抽屉焦点、Escape 返回与存档失败重试。
5. **三档倍速**：HUD 循环 1× → 2× → 3× → 1×，开发者面板提供 3×。不同档位有独立底色，模拟继续采用不超过 0.05 秒的子步推进。
6. **无尽模式**：第十波清场后先持久化正常胜利奖励，再让玩家选择直接领奖或原阵容进入第十一波。无尽追加结算使用独立收据，只追加无尽金币/碎片与最高波次，不重复发星、胜场或扭蛋券；失守/暂停收官均显示金盾荣誉结算。存档写入失败时显示重试，未保存的标准奖励不能进入无尽。
7. **右侧被动栏**：被动道具移到棋盘右侧景深区，显示等级、点击/悬停说明。备战时六个槽位可从空槽直接进入黑市背包；开战后隐藏空槽。右侧单位属性卡给被动栏让出空间。

原有护主大肥橘、狂欢派对仍是自动生效的被动装备，未改变它们的配置类型。P12 连续动画与已调优的近远程数值保持。

HP 相对原始怪物基数，另叠加既有段位/装备修正。第十一波起速度每层加 6%（上限 75%）、护甲每层加 2.5%（上限 35%），怪量上限 56，间隔下限 0.55 秒。首领错峰排期与预告使用独立随机源，不改变抽卡随机序列。

标准奖励与无尽奖励各自只入账一次；重复点击、重复回调及保存失败后重试均有回归测试。用洒水车击杀最后一只怪后立即暂停收官，也会计入已完成波的悬赏；尚有待刷怪物/副首领时不会提前发奖。
