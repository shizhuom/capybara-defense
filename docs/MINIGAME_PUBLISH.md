# 卡皮巴拉别慌 · 微信 & B站小游戏构建与提审指南

> 适用分支：`wechat`（网页版保持在 `main` 分支零改动）

## 1. 本地构建命令
在 `games/capybara-defense/` 目录下运行：

```bash
# 构建微信小游戏包 -> dist-wx/（自动保留 project.config.json 中已绑定的 AppID）
npm run build:wx

# 构建 B站小游戏包 -> dist-bl/
npm run build:bl

# 浏览器快速预览小游戏 Canvas UI（支持 Chrome 手机模拟）
npm run dev
# 打开 http://localhost:5173/minigame.html
```

当前包体（远低于微信/B站 4.00 MB 主包红线）：
- **主包**：`~1.84 MB`（核心代码 + 开场/首图/英雄/基础宠/战斗图标）
- **本地分包 `subpackages/maps`**：`~0.75 MB`（樱花温泉馆、深夜厨房、猫爬架迷宫、温泉山庄庭院与设施）
- **本地分包 `subpackages/meta`**：`~1.18 MB`（36 把神兵、14 道汤浴、食材、16 头像、觉醒立绘与高级首领）
- **总包体**：`~3.78 MB`（零外置 CDN 依赖）

## 2. 微信小游戏导入、真机调试与提审
1. 打开 **微信开发者工具**，左侧选 **小游戏** → 导入目录 `D:\rea_game\games\capybara-defense\dist-wx`。
2. 点击顶部 **「编译」**（`Ctrl + B`）即可在模拟器试玩；点 **「预览」** 扫码真机体验。
3. **全球排行榜联网域名配置**（可选，未配置时自动降级本地榜不报错）：
   - 登录 [微信公众平台](https://mp.weixin.qq.com/) → **开发管理 → 开发设置 → 服务器域名 → `request合法域名`**；
   - 添加已备案的 HTTPS 排行榜接口域名（或自建转发至 Cloudflare Worker 的备案子域）。
4. **提交审核上线**：
   - 在微信公众平台完善小游戏名称、头像、类目（`游戏 > 休闲游戏 > 策略`）与《自审自查报告》；
   - 个人主体无内购（纯免费 / 后期激励视频广告）免版号；
   - 在微信开发者工具点击 **「上传」** → 到公众平台「版本管理」提交审核。

## 3. 流量主激励视频广告接入（满 500 UV 开通后）
代码中已预埋全部 5 个无痛高转化激励视频点位（未填广告位 ID 时自动隐藏，零空按钮）：
1. 战败急救复活（`+2 橘子` 并全路击退，每局 1 次）
2. 通关结算双倍金币
3. 浣熊黑市看视频免费抽 1 次扭蛋
4. 浣熊黑市看视频免费刷新今日货架
5. 温泉山庄离线双倍收菜

开通微信流量主后，在 `src/minigame/adConfig.ts` 或构建环境变量填入广告位 ID（如 `VITE_WX_AD_REVIVE=adunit-xxxx`）再执行 `npm run build:wx` 即可生效。

---

## 4. B站小游戏同步上架
1. 在 B站小游戏开发者平台注册个人开发者账号并创建小游戏项目，下载 B站开发者工具；
2. 执行 `npm run build:bl`，将生成的 `dist-bl/` 目录导入 B站开发者工具（复用同一套 `src/platform/minigameAdapter.ts`，自动识别 `bl` 全局 API）；
3. 打包上传提审即可。
