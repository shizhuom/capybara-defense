## 重要问题

### P2 — 同步目标的符号链接可能绕过游戏目录写入边界（Round 1：ADDRESSED，已关闭）

位置：`scripts/sync-assets.mjs:13`、`:15`、`:17`。

`pngNames()` 在源扫描时使用 `Dirent.isFile()`，确实会跳过源符号链接，但复制阶段直接对 `targetDir/<name>.png` 调用 `copyFile()`，没有检查已有目标文件是否为链接；写 manifest 时也直接 `writeFile()`。当游戏内存在同名 PNG 或 manifest 链接、或者 `public/sprites` 本身为目录链接时，写入可跟随链接落到游戏目录外，违反规格第 0 节的写入隔离要求。目标扫描在复制之后，不能阻止这次写入；README 中“symlinks are skipped”也未覆盖此情况。

建议在写入前核验实际目标目录仍位于游戏目录内，拒绝已有目标文件/manifest 的符号链接，或使用游戏内临时文件与替换链接本身的安全发布方式。补充游戏目录内的链接夹具测试，验证被链接的文件不会被覆盖。本次只读审查没有创建链接、运行同步或执行越界写入；实际目标目录内未发现符号链接，因此现有 133 张文件没有观察到污染。
