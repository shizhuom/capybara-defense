## 问题

### Minor：结算保存失败时的反馈与实际状态不符

- 位置：`src/ui/GameApp.ts:208`、`src/ui/GameApp.ts:214`、`src/ui/GameApp.ts:436`、`src/ui/GameApp.ts:442`；被沿用的文案位于 `src/i18n/zh-CN.ts:78` 与 `src/i18n/en.ts:69`。
- 条件：本局正常结算，但该次 `saveProfile(award.profile)` 返回 false，例如浏览器暂时拒绝存储。代码正确保留旧 profile，没有提前提交奖励、星数或收据；然而提示仍为“本次记录保留在当前页面 / this page still remembers your result”。离开结果页后没有将本次奖励提交到页面 profile，也没有重新保存该结算的入口。
- 额外可见后果：若结算为失败且原段位 ≥10、原星数 >20，保存失败使 `resultStars` 保持 0，结果页会错误显示“20 星底线保护”。这实际上是保存失败，并非触发了星数保护。
- 建议：失败时明确说明本局进度未保存；仅在结算成功保存后展示保护/晋级等已应用进度提示。保持现有保存成功后再提交内存的事务约定。
- 判定依据为确定的源码分支；现有浏览器存储失败检查覆盖设置，不覆盖此结算提示。本审查未为该提示问题修改存档或运行浏览器探针。
