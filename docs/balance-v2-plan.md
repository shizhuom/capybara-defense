# M1 数值与五连抽调整

依据：用户试玩后的新指令优先于旧 M1 文档中的单抽、波次与铲子产出数值；原版与 design 文件保持只读。

目标：开局有时间摆阵，普通宠能应付前期杂兵，二哈破坏速度不压过玩家恢复能力；10 口粮抽取 5 个单位，允许未摆完就弃掉窝内剩余单位再抽一窝。

执行：

1. 保存当前 M1 源码快照到本项目 backups/m1-before-balance.zip。
2. 从已恢复的《赵云与阿斗》代码/运行时核对召唤、敌人、首领和铲子数值，将观察与本作调整分开记录。
3. 先写五连抽/弃牌/费用/暂停边界回归；实现原子操作，口粮不足时既不扣费也不丢卡，场上及对手单位保持不变。
4. 调整开局、波次、敌人、二哈及铲子产出；同步 AI 与双语界面，从实际波次仿真检查效果。
5. 全部测试、构建、实际浏览器操作及启动版本更新；再次核对保护文件。

界面决策：窝空时显示「摇铃开饭」，窝内有单位时显示「换一窝」和将丢弃的数量、花费及新抽数量；点击后一次完成弃牌重抽，不另加确认弹窗。

技术保持 TypeScript/Vite/Canvas/Vitest，端口4175、存档前缀与模块隔离不变。具体参考数值及适配理由将在 reference-balance.md 和本作变更记录中补齐。

执行完成：修改前源码快照已保存；原版只读调查、五连抽/重抽、前期数值、双语界面与 AI 同步已实现。106 项单元测试、20 项浏览器检查、生产服务交互、30 种子完成结算仿真及 2094 文件隔离校验均通过。详情见 [balance-v2-verification.md](balance-v2-verification.md)。
