## Findings

- **Important — preserve slash presentation at attack creation, instead of consulting the current source.** `src/render/CombatEffects.ts:17` derives hero ring size and awakening from `heldWeapon(unit, loadout)`, which returns null after that unit moves to the bench or disappears. A captured `spin360` event from Kungfu Po therefore changes from a 185px hero ring to a 145px basic ring and loses its awakened heavy overlay if the hero is moved/merged/removed during the 0.33s animation. Empowerment similarly reads the current counter after the attack has already decremented it (`src/core/BattleEngine.ts:337`). `src/render/StickerRenderer.ts:474` attempts to reconstruct critical state from any recent red damage number near the target, so an unrelated ultimate can enhance an ordinary slash, and the enhancement can change during an event's lifetime. Capture source kind/hero status and enhanced/critical state with the slash event and consume those fields; root may need to coordinate the small event-contract change. Add a focused assertion that the same event retains size, chosen art and enhancement after moving/removing its source and after adding unrelated critical damage. The existing missing-source tests check only that some geometry is drawn, so they do not catch this regression. Captured projectile theme and slash origin/target/style are otherwise correctly retained.

- **Important — normalize equipped sticker axes per asset, not only the default signatures.** `src/render/HeldWeaponRenderer.ts:76` handles the inspected default stickers, but every other melee sticker falls back to a 90° correction and every other ranged sticker to 0.4 radians. This is incorrect for supplied diagonal art. For example, `public/sprites/weapon_m01_swatter.png` has its handle-to-head axis roughly 45° upward/right; the fallback turns that axis roughly 45° away from the requested aim/radial direction, rather than aligning it with `pose.rotation`. Equipped Kungfu Po consequently swings that weapon obliquely instead of with its striking end outward, despite the default bamboo staff being corrected. The same generic assumption affects nondefault ranged art and can separate the visible barrel direction from the muzzle drawn along local +X. Provide per-asset aim corrections (or authored axis metadata) for the directional equipped art and reuse the corrected coordinate frame for flash placement. Add a focused draw-transform test for at least one diagonal nondefault melee weapon and a nondefault ranged weapon, aimed both left and right. The current 36-weapon test validates IDs/scales only. This finding is based on supplied asset axes and transform composition, not on unproduced integration screenshots.

- **Minor — cross slash skips the specified first-quarter windup.** `src/render/HeldWeaponRenderer.ts:28` starts immediately at -65° and sweeps forward over the first half, then reverses. Unlike the neighboring cleave branch, it has no first-25% windup as required for `cleave180 / cross_slash` in §4.3.3. Apply the windup before the twin-swing phase while preserving its reverse stroke; test the quarter-boundary pose rather than only the symmetry between quarter and three-quarter poses.
